# Smart Study Planner

## Introduction
Smart Study Planner is a simple web application developed using Python Flask. The application helps students generate a study schedule based on the subject name, number of chapters, and available study days.

The project is deployed on a cloud platform using Render and the source code is hosted on GitHub.

---

## Features
- Accepts subject name
- Accepts number of chapters
- Accepts available study days
- Automatically generates a daily study plan
- Simple and user-friendly web interface
- Cloud deployment support

---

- Flask

- SQLite
